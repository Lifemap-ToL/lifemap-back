# Normalized taxonomy datasets

Each source has one `formatted_data` directory containing the current files:

```text
data/taxonomy_datasets/
├── ncbi/
│   ├── downloads/
│   └── formatted_data/
├── gbif/
│   ├── downloads/
│   └── formatted_data/
├── ott/
│   ├── downloads/
│   └── formatted_data/
└── catalogue_of_life/
    ├── downloads/
    └── formatted_data/
```

Only the current formatted dataset is kept locally.
